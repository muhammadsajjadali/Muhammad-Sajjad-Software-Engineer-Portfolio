# Muhammad Sajjad | Software Engineer Portfolio

A modern, responsive, and professionally designed personal portfolio website showcasing Muhammad Sajjad's skills, projects, education, and journey as a Software Engineer.

Built using pure HTML, CSS, and JavaScript with a modern dark-themed design.

## 🚀 About The Project

This portfolio website represents my professional identity as a Software Engineer. It provides a platform to showcase my technical skills, programming projects, and development experience.

The website focuses on clean UI, modern design, smooth interactions, and responsive layouts.

## ✨ Features

- Modern dark-themed interface
- Fully responsive design
- Professional hero section
- About Me section
- Technical Skills showcase
- Featured Projects
- Assembly Language project showcase
- Education and Experience
- Contact section
- Smooth scrolling
- Interactive navigation
- CSS animations and transitions

## 🛠️ Technologies Used

- CSS3 – Styling, layouts, animations, and responsiveness

## 💻 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/muhammad-sajjad-portfolio.git
```

### 2. Navigate to Project Folder

```bash
cd muhammad-sajjad-portfolio
```

### 3. Open the Website

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
